# 五行行业轮动分析 Skill 使用说明

## 快速开始

### 1. 直接运行脚本
```bash
# 分析指定年月
python3 scripts/five_elements_analysis.py 2026 7

# 使用自然语言输入
python3 scripts/run_analysis.py "分析2026年7月的五行行业"
```

### 2. 在对话中使用
用户可以直接说：
- "分析2026年7月的五行行业"
- "2026年8月五行看什么行业？"
- "今年各月的五行分析"

## 功能特性

### 1. 月令五行计算
- 自动计算月令天干地支
- 判断月令五行属性
- 识别特殊格局（伏吟、燥土等）

### 2. 五行旺衰分析
- 分析当月五行旺衰状态
- 旺、相、休、囚、死五种状态
- 五行生克关系判断

### 3. 行业映射预测
- 五行属性→行业板块映射
- 主线行业、支线行业、回避行业
- 龙头行业推荐

### 4. 操作建议生成
- 基于五行旺衰的投资建议
- 结合特殊格局的策略调整
- 风险提示和注意事项

## 输出说明

## 知识库说明

### 天干地支五行
- 十天干：甲乙丙丁戊己庚辛壬癸
- 十二地支：子丑寅卯辰巳午未申酉戌亥
- 五行属性：木火土金水

### 行业五行分类
- **火属性**：半导体、AI、新能源、电力
- **木属性**：医药、环保、农业
- **水属性**：物流、旅游、传媒
- **金属性**：金融、机械、军工
- **土属性**：房地产、基建、资源

### 特殊格局
- **伏吟**：年支与月支相同，五行力量叠加
- **燥土**：未、戌土，内藏火气
- **湿土**：辰、丑土，内藏水气

## 注意事项

1. **理论局限性**：五行理论为传统文化分析方法，需结合现代金融分析
2. **数据依赖**：当前版本基于理论推演，未接入实时行情数据
3. **风险提示**：投资有风险，决策需谨慎
4. **持续优化**：建议结合历史数据回测，不断优化预测模型

## 扩展功能
