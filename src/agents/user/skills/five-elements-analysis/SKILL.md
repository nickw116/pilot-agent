# 五行行业轮动分析 Skill

## 概述
基于中国传统五行理论（天干地支、月令五行、生克制化）分析股市行业轮动规律，提供专业的行业配置建议。

## 核心功能
1. **月令五行计算**：根据日期计算月令天干地支及五行属性
2. **五行旺衰分析**：分析当月五行旺衰状态
3. **行业映射预测**：将五行旺衰映射到相关行业板块
4. **轮动节奏判断**：预测行业轮动节奏和主线行业

## 触发条件

- 行业轮动

```
用户：2026年7月五行看什么行业？
用户：分析下今年各月的五行行业轮动
用户：丙午年午月火旺，哪些行业会涨？
```

## 核心算法
1. **月令计算**：根据节气确定月支，根据年干推算月干
2. **五行旺衰**：月令五行当旺，相生五行次旺，相克五行受制
3. **行业映射**：五行属性→行业板块→龙头个股
4. **特殊格局**：伏吟、反吟、燥土、湿土等特殊判断
