## 🔧 使用方式

### 1. 命令行直接调用
```bash
# 分析指定年月
python3 scripts/five_elements_analysis.py 2026 7

# 自然语言输入
python3 scripts/run_analysis.py "分析2026年7月的五行行业"
```

### 2. 在对话中调用
用户可以说：
- "分析2026年7月的五行行业"
- "2026年8月五行看什么行业？"
- "今年各月的五行分析"

### 3. 编程接口调用
```python
from scripts.five_elements_analysis import generate_report, format_report

report = generate_report(2026, 7)
print(format_report(report))
```
