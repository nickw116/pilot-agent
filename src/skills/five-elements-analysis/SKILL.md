# 五行行业轮动分析 Skill

## 概述
基于中国传统五行理论（天干地支、月令五行、生克制化）分析股市行业轮动规律，提供专业的行业配置建议。

## 核心功能
1. **月令五行计算**：根据日期计算月令天干地支及五行属性
2. **五行旺衰分析**：分析当月五行旺衰状态
3. **行业映射预测**：将五行旺衰映射到相关行业板块
4. **轮动节奏判断**：预测行业轮动节奏和主线行业

## 核心算法（对齐命理通用口径）
1. **节气换月**：每月以"节"交界换月令（立春2.4起寅月=正月），**不是农历初一、也不是公历1号**。寅卯辰=春、巳午未=夏、申酉戌=秋、亥子丑=冬。
2. **月令力量模型（多维）**：不只看月支主五行，而是综合——
   - 月支本气 + 藏干（中气/余气）
   - 月干透出（如庚寅月庚金有力）
   - 四库库性：辰=水库、戌=火库、丑=金库、未=燥土藏火
   - 流年加权（年柱为背景，年支月支同气叠加、相冲减损）
3. **刑冲会合**：六冲（子午、丑未、寅申、卯酉、辰戌、巳亥）。月支冲年支（如子月冲午年=子午冲，全年水火冲突最重）需重点提示。
4. **调候用神**：火旺之年，遇水月/湿土月（辰、亥子）为"降火调候喜月"，喜金水、忌火土之人全年利好。
5. **月份流转承接**：分析当月须承接前月余气——如未月"火转入土、火气收敛"、申月"火余气仍在"、戌月"火藏土中不外露"。
6. **旺衰强度分组**：输出"旺：木＞金；偏弱：水、土"式（带强度排序+分组），而非仅定性"旺相休囚死"。
7. **行业映射**：五行属性→概念板块（混合派：传统五行→半导体/HBM/光伏/券商等细分）。

## 输出口径对齐要点
分析结论须与命理通用结论一致（以丙午2026年为例）：
- 午月（甲午）= 年月双午**火气全年极值**（火气最旺）
- 辰月（壬辰）= **水库**，水土同旺，全年降火调候最佳月
- 未/戌月 = 燥土主导、藏火余气
- 申/酉月 = 金旺（酉月为全年金气最高点）
- 子月（庚子）= 金水旺 + **子午冲**流年，全年水火冲突最重
