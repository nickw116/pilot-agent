# 二/三因子四象限分析法（2D-3D Quadrant Analysis）

> ⚠️ **强约束（最高优先级，不得违反）**：本 skill 是「行业/产业分析」与「象限/三维坐标打分」类问题的**唯一标准框架**。当用户提到"三象限 / 四象限 / 三维坐标 / BCG 矩阵 / 分象限 / 维度打分 / 不可替代性 / 业绩弹性 / 持续性"等任一触发词时，**无论什么赛道、无论用户是否指定行业**，都必须使用本 skill 的标准三维 **X=不可替代性 × Y=业绩弹性 × Z=持续性** 框架，**禁止替换为行业特定方法论**（如化纤的"供给/需求/价差"、半导体的"国产化/卡脖子/弹性"等行业研究员习惯的供需平衡框架）。
>
> 行业方法论只能在「选维度」步骤中作为**轴含义的具体化解释**，不能替换三个轴本身。若用户明确纠正三个轴的定义（如"我说的三象限是 A/B/C"），按用户纠正执行，但要在回复里确认一次。
>
> 违反本约束 = 严重错误（已在 2026-07-06 会话中发生过：把化纤三象限错做成"供给/需求/价差"，被用户纠正）。

> **一句话本质**：用 2-3 个**正交的核心维度**把研究对象（行业环节/公司/产品）分成若干类，定位"最该投 / 最该避开"的位置。是 BCG 矩阵（Bruce Henderson, 1970）的二维/三维扩展，也是产业研究与选股排序最实用的"瑞士军刀"。

> **🎯 本 skill 是"行业/产业分析"的默认框架**。当用户要求做任何**产业分析、产业链梳理、行业格局拆解、景气度排序、龙头筛选**时，**默认优先加载本方法**并用四象限/三维坐标把产业结构化——而不是平铺直叙地罗列环节。先画出"产业全景四象限"，再逐环节展开。

本 skill 提供一套可复用的：维度选择 → 方向定义 → 象限定位 → 解读排序 → 动态迁移 的完整流程。

## 一、方法定义

| 版本 | 维度数 | 分类数 | 适用 |
|------|--------|--------|------|
| **二因子二维四象限** | X × Y | 4 类（2²） | 对象 ≤ 8 个，快速判断 |
| **三因子三维坐标系** | X × Y × Z | 8 类（2³） | 对象 8~30 个，精细排序 |

三个维度**默认全部"越大越好"**（若某维度越小越好，分析时翻转即可）。

### 维度选择的三个硬条件（选错维度全盘皆输）

| 条件 | 含义 | 反例 |
|------|------|------|
| **正交性** | 两维度相互独立，不能高度相关 | "定价权"和"市占率"高度相关 → 不可 |
| **分辨力** | 能把研究对象有效分开 | 不能让 80% 对象堆在同一个象限 |
| **可量化** | 至少能半定量打分（1~10 分） | 不能用"感觉好"这种模糊词 |

## 二、标准 4 步流程

### 步骤 1️⃣ 选维度（最关键）
- 二维：选 2 个**正交**维度
- 三维：再加 1 个**独立**维度（常用：持续性 / 估值 / 市值）

### 步骤 2️⃣ 明方向
每个维度回答"越大越好还是越小越好"，统一标到坐标轴。

### 步骤 3️⃣ 填象限
把每个对象按打分放进对应象限/坐标点。

### 步骤 4️⃣ 解读 + 排序
四象限投资含义（二维）：

| 象限 | 类型 | 策略 |
|------|------|------|
| **右上**（高 X + 高 Y） | 明星 Star | ⭐⭐⭐⭐⭐ 重点配置 |
| **左上**（低 X + 高 Y） | 现金牛/周期股 | ⭐⭐⭐ 跟随周期 |
| **右下**（高 X + 低 Y） | 稳健防御 | ⭐⭐ 抗跌弹性低 |
| **左下**（低 X + 低 Y） | 瘦狗 Dog | ⭐ 回避 |

三维扩展时，在 X-Y 平面定位后，**再用 Z 轴（常用=持续性）做二次排序**，得到最终优先级。

## 三、三维坐标系要点（本 skill 的核心扩展）

经典三维轴定义（投资场景最常用）：

| 轴 | 维度 | 含义 | 判断方法 |
|----|------|------|---------|
| **X** | 不可替代性 / 定价权 | 越右越稀缺，越能涨价 | 全球玩家数、专利、标准制定权、客户验证绑定 |
| **Y** | 业绩弹性 | 越上越爆发 | 量增×价升的乘数，与行业景气周期的相关度 |
| **Z** | **持续性** | 越深越持久，能穿越周期 | 见下方"持续性 5 问" |

> **关键心法**：**X+Y 强 + Z 弱 = 烟花股**（爆一下就熄）；**X+Y 中 + Z 强 = 真龙头**（慢慢涨不停）。选股时三个维度都重要，但 **Z（持续性）决定能不能拿住**。

### 持续性（Z 轴）判断 5 问

| # | 判断问题 | 高分（持续性强）特征 |
|---|---------|--------------------|
| 1 | 代际更替频率 | 越频繁越持续（如 DDR 子代 1~2 年迭代 > 普通品类） |
| 2 | 客户绑定深度 | 验证后绑定越深越持续（设备/标准 > 模组成品） |
| 3 | 技术替代风险 | 越难被新技术颠覆越持续 |
| 4 | 标准制定权 | 参与 JEDEC/行业标准 = 持续性高 |
| 5 | 护城河深度 | 全球玩家 ≤ 3 家 = 持续性高 |

> 持续性可由两个相反路径达到同样高分：**"代际长"**（如薄膜沉积设备 5~10 年/代）或 **"迭代密"**（如内存接口芯片 1~2 年/子代），殊途同归。

## 五、三种进阶扩展

1. **加第三维度（3D 气泡图）**：气泡大小=市值/营收，颜色=估值高低。适合 10~30 个对象。
2. **加时间维度（动态轨迹）**：同一对象在 2020/2022/2024/2026 的位置连线，看**象限迁移方向**——比看当前象限更有价值（例：某标的从左上→右上 = 景气度提升、定价权增强）。
3. **叠加行业生命周期**：在四象限上叠加"导入/成长/成熟/衰退"色块。右上+成长期=最佳（量价齐升+不可替代）；左下+衰退期=最差。

## 六、优缺点与避坑

| 优点 | 说明 |
|------|------|
| 简洁直观 | 一张图讲清"为什么投 A 不投 B" |
| 易于沟通 | 给老板/客户 1 分钟讲明白 |
| 快速排序 | 不用先看 PE/PB，10 秒判断要不要看 |
| 可复用 | 同一框架套任何行业/产品/公司 |

| 缺点 | 避坑方法 |
|------|---------|
| 维度简化失真 | 2 维不够就上 3D 或雷达图补充 |
| 静态无时间 | 加时间维度看象限迁移 |
| 边界象限难分 | 用 1~10 打分制而非 0/1 硬划分 |

## 七、标准输出格式（汇报给用户时遵循）

执行四象限分析时，按以下结构输出：

1. **坐标轴定义**：明确每个轴是什么、方向（越大/越小越好）；三维须列出 Z 轴。
2. **打分表**：每个对象在 X/Y/Z（各 1~10 分）+ 简要依据。
3. **象限定位图**：ASCII 坐标图或表格，标出对象位置。
4. **排序结论**：综合得分排序，给出投资策略（重点配置 / 跟随 / 防御 / 回避）。
5. **（可选）动态迁移**：指出哪些对象正在跨象限迁移及方向。

打分表示例：

| 对象 | 不可替代性(X) | 业绩弹性(Y) | 持续性(Z) | 定位 |
|------|-------------|-----------|---------|------|
| A 环节 | 9.0 | 8.0 | 9.5 | 🥇 长坡厚雪 |
| B 环节 | 9.5 | 9.5 | 7.5 | 🥉 短期高爆 |
| C 环节 | 4.0 | 8.0 | 6.0 | 高弹低护城 |

## 七½、产业分析默认流程（通用行业通用）

当用户要求"分析 XX 产业链 / 梳理 XX 行业格局"时，不要平铺罗列，而是**用本框架把产业结构化**，按以下 5 步：

1. **拆产业链环节**：把行业从上游→中游→下游拆成 4~8 个关键环节（设备/材料/核心器件/配套/成品/应用）。
2. **选维度**：从「维度组合模板」中挑 2~3 个适合该行业的轴。**默认三维**：X=不可替代性/定价权，Y=业绩弹性，Z=持续性；若行业特性明显（如消费看品牌/渠道、周期看集中度），换用更贴切的轴。
3. **逐环节打分**：每个环节在 X/Y/Z 各打 1~10 分，附一句依据。
4. **画产业全景象限**：输出一张四象限/三维定位图，把环节标进去。
5. **出结论**：综合排序 → 标出"重点配置（右上）/ 跟随（左上）/ 防御（右下）/ 回避（左下）"，并点名 A 股对应龙头标的。

> 提示：先全景后细节。先用一张象限图让用户看清"哪个环节最值得投"，再就用户感兴趣的环节深入展开（量价逻辑、竞争格局、标的）。

## 八、完整案例：存储产业链三维分析

来源：财联社科创板日报四象限图 + 用户校准的三维坐标系。

- **X 轴**：不可替代性 / 定价权（→）
- **Y 轴**：业绩弹性（↑）
- **Z 轴**：持续性（对角深度，紫色箭头）

Z 轴（持续性）排序：**薄膜沉积 ≈ 内存接口芯片 > 原厂 HBM > 模组 > 普通内存**

| 产业 | X 不可替代 | Y 弹性 | Z 持续性 | 定位 |
|------|----------|-------|---------|------|
| 薄膜沉积设备 | 8.0 | 7.5 | 9.5 | 🥇 长坡厚雪（代际长 5~10 年） |
| 内存接口芯片 | 9.0 | 8.0 | 9.5 | 🥇 长坡厚雪（迭代密 1~2 年/子代） |
| 颗粒原厂(HBM) | 9.5 | 9.5 | 7.5 | 🥉 短期高爆（渗透见顶风险） |
| 模组 | 4.0 | 8.0 | 6.0 | 高弹低护城（门槛低、毛利低） |
| 普通内存 | 3.0 | 4.0 | 3.0 | 夕阳品类（DDR4 减产） |

> **核心洞察**：右上象限的三个环节（颗粒原厂、薄膜沉积、接口芯片）在 X-Y 平面都靠右上（高不可替代+高弹性），但靠 **Z 轴持续性**才分出真正优先级——薄膜沉积与接口芯片才是"长坡厚雪"的真龙头。
